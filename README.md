Machine Learning project that predicts salary based on a person’s:

 Age,
 Years of Experience,
 Gender, 
 Education Level

---> Had to drop out "Job Title" as it was impacting the R2 value.

This project was built using Python and Scikit-learn to understand the complete ML workflow — from data preprocessing to model training, evaluation, visualization, and user prediction.


Evaluates model performance using:-
    * MAE,
    * MSE,
    * RMSE,
    * R² Score


Technologies Used:-

 Python,
 Pandas,
 NumPy,
 Matplotlib,
 Scikit-learn
